# Header notifications and sidebar cleanup

The shared sidebar no longer lists Announcements or Notifications for any role. Empty Communication was removed for admin; existing messages/emergency navigation for other roles remains. Header links retain access to each role's existing full notification and announcement pages.

The existing Bootstrap bell dropdown and notification API are reused. The dropdown includes title/message/type/actual timestamp/read state, unread highlighting, individual Mark as Read, Mark All as Read, a scrollable list, full Notification Center link and Announcements link. Bootstrap outside-click dismissal is retained (auto-close outside); reduced-motion CSS is provided. The existing 30-second poller is reused, requests are guarded against overlap, and a queued refresh follows concurrent read mutations. Badge counts come from the authenticated user's database count, cap at 99+, and hide at zero.

Read/details/delete mutations require POST and CSRF. The full Notification Center details caller was updated to POST so its existing automatic read behavior remains functional. All queries remain scoped by authenticated user_id. Detailed SOS enrichment is restricted to admin/nurse. Existing SOS bell details and the independent full-screen global overlay are preserved. Marking notifications read never changes overlay receipts or emergency status.

Announcements publish notifications to active users in the existing target audience, excluding the publisher. Student and teacher announcement views correctly map role names to plural audience values; admin/nurse management access remains. Delivery uses an advisory lock and checks announcement ID plus recipient, irrespective of whether an earlier notification has been read. Distinct announcements with the same generic title no longer suppress each other. No existing data was deleted and no schema change was needed for this notification update; it uses the existing related_id/read_at metadata columns.

Validation: PHP lint, JavaScript syntax, notification renderer fixtures (badge/count/escaping/empty/SOS), announcement delivery deduplication fixtures, role-scoped sidebar rendering, and notification endpoint fixtures for ownership, individual/all-read operations and CSRF. Read-only database check found a sample admin unread count of 4 and confirmed metadata columns. Global SOS PHP/JS regression fixtures passed. Browser dropdown clicks, outside-click behavior and mobile visual rendering were not exercised.
